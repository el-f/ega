# Rules-editor surface rubric

## Mount + render

- The Rules card is on the Glossary and rules tab: title "Rules" with an (i) "About rules", and one line "Extra instructions for every task or only some".
- One row per rule: a checkbox named "Use rule: <rule text>", the full rule text (it wraps, never cut), and "Edit" at the end. Under the text, one muted line: type, tasks and sites joined with a middle dot, like "Always · All tasks · twitter.com".
- Type names are words: Always, Never, Prefer, Format, Other. No "RULES (n)" heading, no "On" or "Off" words, no boxes around rows; a hairline separates them.
- Empty: "No rules yet", "For example: Keep product names in English" and a primary "Add rule". The header "Add rule" shows only once rules exist.

## Add / edit / delete

- Edit opens the fields under the row and moves focus to the rule text; Edit becomes "Close". Esc closes and returns focus to Edit.
- Each field saves when it is left; "Saved" shows by the Delete rule button.
- "Add rule" opens the same fields at the top as a draft, with a primary "Add rule" and a ghost "Cancel".
- Delete rule removes it at once and shows Deleted "<rule>" with Undo (no confirm).
